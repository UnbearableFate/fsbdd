## GREEN and hardening

Each fragment has one fixed current record naming one binary compound payload:
parameters, outer state, metadata, and at most `S_max + 1` embedded bases.
Bootstrap validates all existing version-zero content before publishing only
missing fragments. A partial snapshot fails, identical restart publishes
nothing, and conflicting content is rejected before current authority changes.
`publish_successor` derives version and outer-update count as previous plus one;
the caller cannot supply either ordinal.

The selected two-node run interrupts after two of four fragments. The remote
reader rejects the partial snapshot; resume preserves indices 0/1 and publishes
only 2/3. The final vector is `[0,0,0,0]`, four current records reference four
payloads, and four retained bases meet the `F*(S_max+1)` bound. After injecting
10,000 unrelated payload objects, a full restart still performs exactly four
backend reads, identical to baseline, with no global-head read or normal-path
directory scan. All 79 Stage 1 tests pass, including exact round-trip of every
owned tensor from a seeded tiny real Hugging Face GPT-NeoX model.
