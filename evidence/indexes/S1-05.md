## GREEN and hardening

writes and validates one complete compound proposal payload before the slot
becomes visible. Discovery performs exactly `M*F = 32` fixed reads both before
and after 10,000 unrelated objects, without a normal-path directory scan.
Remote payload-only state is invisible; completing the publish makes it
visible. Repeating the same sequence is idempotent, conflicting same-sequence
content is rejected, and a delayed sequence 2 task cannot replace sequence 3.

The decoded 32,768-byte proposal binds run/config/model/map, learner, fragment,
base version and content identity, local progress, dtype/shape, checksum, and
the complete local parameter bytes. Formal selection chooses eight distinct
learners for each of four fragments. A committed fragment-bound frontier holds
exactly eight learner entries, and the immediate repeated poll selects zero and
rejects all eight as already consumed. Shared Stage 0 decision vectors and
permutations pass. The float32 weights implement
`processed_tokens/(1+lambda_s*staleness)` and normalize within `2e-6` of the
oracle. Formal runtime uses `S_max=0`; the same generic production path has
positive-`S_max` test coverage and is coupled to the checked S1-04 retained-base
component. All 119 Stage 1 tests pass.

## Known limitations

- Formal cross-node proposals contain deterministic bytes; S1-05 does not
  perform snapshot generation, merge, or learner training.
- The monotonic latest result relies on the frozen one writer and one in-flight
  publication per learner/fragment invariant. Multiwriter arbitration is not
  claimed and storage correctness uses no filesystem lock.
- Formal selection is fresh-only (`S_max=0`). Positive stale eligibility and
  weighting are production/test evidence here; later Stage 4 loops exercise
  delayed real proposals.
- The frontier proves fixed-state once-only selection. Atomic joint publication
  of parameters, outer state, and consumed frontiers is S1-11 work.
- Physical garbage collection is outside this loop; discovery and correctness
  are independent of unreferenced proposal history.
