## 单一目标

实现单逻辑syncer的per-fragment readiness state machine、distinct-learner quorum、固定grace与确定性无饥饿调度；S_max=0。

## 非目标

- 不做merge/commit
- 不做adaptive grace
- 不做多syncer

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 SYNC-01..05/09、STALE-09、INV-02；
- readiness/grace 状态机的时间源（单调钟）与 tie 处理全序；
- 公平性判定：饥饿计数窗口与无饥饿断言的观察点。

## SPECIFY / RED

- 按文件数而非distinct learner计quorum的实现必须失败。
- CPU loop次数驱动update的实现，在无新proposal时错误ready。
- 持续高频f0导致f1饥饿的scheduler fixture失败。
- selected set受目录顺序/后到proposal改变时失败。

## IMPLEMENT / GREEN

- 固定current version并读取eligible candidates；Q/Q_fresh readiness。
- grace start/end明确；grace后freeze selected set。
- round-robin或确定性age-based无饥饿调度。

## HARDEN

- multiple fragments ready、late arrival、duplicate slots、quorum loss/recovery。
- clock/tie deterministic；restart可从authority重建 readiness。
- polling history独立。

## Miyabi Final Gate

不适用：CAP-BASE-TRAINING 尚未建立，首次 9N gate 在 `S1-13`。

## CHECK

- Checker用不同目录返回顺序重放。
- 核对Q=M/grace=0 Profile A。

## PERSIST 输出

- syncer readiness machine
- selection traces
- fairness tests
- quorum/grace evidence

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- quorum/grace/公平/重放确定性断言全部通过、restart 可从 authority 重建即关闭；
- merge/commit 留给 S1-10/S1-11；不做 adaptive grace 或多 syncer。
