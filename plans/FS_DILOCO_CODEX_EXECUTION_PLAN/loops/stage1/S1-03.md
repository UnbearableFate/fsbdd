## 单一目标

实现仅依赖原子 visibility record 替换与最终可读的 storage interface，以及 immutable payload-first/visibility-last POSIX backend。

## 非目标

- 不实现 proposal/global业务语义
- 不依赖锁/append/目录事务
- 不做对象存储backend

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 STOR-01、FS-01/02/03/07、PROP-02、INV-04；
- 并发 reader 的权威观察点与 partial/invalid read 判定函数；
- 直接复用 Stage 0 S0B-02 unsafe-overwrite 反例 fixture，不新造检测器。

## SPECIFY / RED

- unsafe direct-overwrite writer在并发 reader test中必须出现 partial/invalid并失败。
- reader尝试扫描payload目录发现最新对象的实现必须被接口 test拒绝。
- checksum/size/schema/base identity任一不匹配必须拒绝。

## IMPLEMENT / GREEN

- write unique temp/immutable final payload，校验后原子替换小record。
- reader只follow visibility record并验证完整性。
- 实现可注入visibility delay的hook接口（真正perf在Stage2）。

## HARDEN

- writer crash before/after payload、before/after record rename；multiple readers。
- record corruption、payload truncation、wrong identity。
- fixed-slot API不暴露history scan。

## Miyabi Final Gate

不适用：CAP-BASE-TRAINING 尚未建立，首次 9N gate 在 `S1-13`。

## CHECK

- Checker检查backend未使用未允许强语义作为correctness前提。
- 复用Stage0-B unsafe case。

## PERSIST 输出

- StorageBackend interface
- POSIX backend
- publication concurrency tests
- A-PROP-01/A-GLOBAL-01 partial evidence

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- unsafe writer/crash 矩阵先红后绿、reader 只 follow visibility record、fixed-slot API 无 history scan 即关闭；
- 不实现 proposal/global 业务语义，真实性能测量留给 Stage 2。
