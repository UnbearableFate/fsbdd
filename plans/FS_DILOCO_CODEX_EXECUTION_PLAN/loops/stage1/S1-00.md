## 单一目标

建立可安装的 Python 项目、角色 CLI 骨架、typed configuration、identity/digest、
structured logging 与通用 run-package builder/finalizer/validator，使后续实现无法绕过
冻结配置或手工拼装不可复核证据。

## 非目标

- 不加载真实大模型
- 不实现 storage protocol
- 不跑9节点

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 DISC-03、ORACLE-05、PROP-01、FS-07、PROG-03/04；
- validator mutation matrix 的 fixture 清单先列全，必须包含 Stage 0 历史缺陷（provenance 不实、requirement 漏项、qtime 不匹配、listed/actual 不一致）；
- evidence package 双 profile 定义：L0/L1 local profile（无 scheduler 字段）与 L2+ PBS profile（完整 identity）；loop 卡最高资源级别决定所需 profile，低级别 loop 不再拼装 PBS 字段。

## SPECIFY / RED

- schema tests：缺 S_max/Q/Q_fresh/H/offset/model/data/storage/stop/seed 字段时失败。
- identity tests：任一 model/fragment/config 字段变化必须改变 digest；canonical ordering 不应改变 digest。
- manifest checker：dirty commit、source hash/skill commit缺失时标记不可作为正式 run。
- run identity tests：timestamp source、execution identity、config digest 任一缺失失败；
  只有声明 `pbs_qtime` 时才强制 timestamp 与 qtime 精确相等。
- package adversarial tests：placeholder、错误 role map、unlisted/extra file、checksum
  mismatch、目录复用、resume identity 不匹配全部失败。
- requirement matrix completeness test 必须从 loop/source 权威 ID 派生，手工漏项失败。

## IMPLEMENT / GREEN

- 创建 pyproject/uv lock 策略、package/CLI skeleton、config dataclasses或schema。
- 实现 resolved config freeze、run_id、SHA-256 digests、UTC/monotonic structured logger。
- 提供 bootstrap/learner/syncer/checker 入口的 dry-run 参数解析。
- 实现 manifest builder、fail-if-exists evidence root、两阶段 checksum finalizer 和
  package validator CLI；validator 输出适合 Checker 直接引用的短 JSON summary。
- manifest 分开记录 submission UTC、PBS qtime/start/end 与 run ID timestamp source，
  不把不同 scheduler 事件强行视为同一时间。

## HARDEN

- unknown field、schema version mismatch、环境变量 override 冲突、路径权限。
- 静态运行不导入 torch/HF重型模块；lazy imports。
- Miyabi 侧本 loop 仅需静态解析/`bash -n`（执行位置按 skill host routing）。
- validator mutation matrix 覆盖 code/config/source/skill/scheduler/roles/checksums；
  对 Stage 0 的历史 provenance/漏项 fixtures 做 regression。

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：
