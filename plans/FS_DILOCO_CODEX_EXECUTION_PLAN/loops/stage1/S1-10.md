# S1-10：Streaming Direct Merge 与 Fragment-wise Outer Optimizer

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage1 |
| 前置 loops | S1-09, S0C-02 |
| 规范条款 | SYNC-06, SYNC-07, OPT-01, OPT-02, OPT-04, OPT-05, OPT-06 |
| Acceptance | A-ALG-01, A-PERF-01 |
| 最高资源级别 | Miyabi 1–2 nodes |
| 9 节点门禁 | 不适用（首次 gate 在 `S1-13`） |

## 单一目标

实现逐proposal读取的fp32 streaming weighted pseudo-gradient、direct merge与per-fragment momentum/Nesterov outer step，对齐Stage0 oracle且不物化M×fragment或完整模型。

## 非目标

- 不实现RDA
- 不做压缩
- 不执行global publication

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 SYNC-06/07、OPT-01/02/04/05/06；
- 与 Stage 0 oracle 对照的数值容差与聚合公式；不同读取顺序的容差判定；
- peak-memory 断言的测量点（RSS/allocator 统计口径）与上限。

## SPECIFY / RED

- production kernel对oracle golden transitions先失败。
- 错误使用current base代替declared base的注入替身失败。
- 实现若缓存所有M payload，peak-memory assertion失败。
- steady path读取完整模型的spy test失败。

## IMPLEMENT / GREEN

- streaming accumulator；每contribution `G_base-L_local`。
- normalized weights；direct merge plug-in interface。
- fragment-wise outer state；SGD/no momentum/lr=1 controls。

## HARDEN

- 不同读取顺序数值容差、单/多 contributor、极端tokens。
- memory profile与byte accounting。
- 连续50 reference updates无漂移放大。

## Miyabi Final Gate

不适用：CAP-BASE-TRAINING 尚未建立，首次 9N gate 在 `S1-13`。

## CHECK

- Checker独立重算selected set和new params/state。
- 确认outer step应用current state。

## PERSIST 输出

- merge/outer optimizer implementation
- oracle comparison
- memory/byte report
- A-ALG-01/A-PERF-01 evidence

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- production kernel 对齐 oracle golden transitions、50 updates 无漂移、内存/byte 断言通过即关闭；
- 不做 RDA、压缩或 global publication（S1-11）。
