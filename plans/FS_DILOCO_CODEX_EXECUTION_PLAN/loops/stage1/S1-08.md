## 单一目标

后台发现最新global fragment，在安全step boundary只覆盖目标fragment，保留inner optimizer moments，允许跳版本和mixed-version持续训练。

## 非目标

- 不要求所有fragments对齐
- 不默认重置moments
- Stage2前不追求完全重叠

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 LEARN-08..11、GLOBAL-04、INV-09；
- adoption 前后参数/moments identity 的比较方法（hash 粒度、比较时点）；
- mixed-version 连续训练的 loss-finite 判定窗口。

## SPECIFY / RED

- adopt f0后其他fragment参数identity改变必须失败。
- 要求全version vector一致才训练的实现，在mixed-version fixture中死锁/失败。
- 默认重置moments的实现与moment preservation test不符。

## IMPLEMENT / GREEN

- 实现latest poll/fetch/verify、pending adoption、safe-boundary apply。
- 更新base version/content，重置该fragment counters，保留moments。
- version可v→v+k；记录adoption lag。

## HARDEN

- in-flight old-base proposal并存、跳过中间version、重复current、wrong map identity。
- 连续mixed-version训练若干steps，loss finite。
- target fragment tied ownership处理。

## Miyabi Final Gate

不适用：CAP-BASE-TRAINING 尚未建立，首次 9N gate 在 `S1-13`。

## CHECK

- Checker比较adoption前后全参数/moments identity。
- 确认没有full model barrier。

## PERSIST 输出

- adoption pipeline v1
- mixed-version system test
- A-LEARN-02/03 evidence
- adoption trace

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- adoption identity/moments 保留/mixed-version 断言通过、连续 mixed-version loss finite 即关闭；
- 异步 adoption 管线优化留给 S2-02。
