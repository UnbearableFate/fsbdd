# S1-01：Hugging Face Model Logical-Layer Registry

| 字段 | 值 |

## 单一目标

对至少两种 decoder-only naming family 建立结构化 logical-layer registry，覆盖 embedding、完整 blocks、lm_head、零散参数和 tied ownership。

## 非目标

- 不做 fragment 切分优化
- 不做 encoder-decoder/MoE
- 不依赖字符串模糊猜测

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 MODEL-01..06 与 A-FRAG-01，每条含 assertion/反例/观察点/证据路径；
- 两个 naming family 的 tiny fixture configs 与“何时要求显式 mapping”的判据；
- 本 loop 只需结构/meta 初始化；真实 160M family 候选（Pythia 风格）记录为 S1-06 profile 输入，不在此冻结。

## SPECIFY / RED

- 构造 Pythia/LLaMA 风格 tiny configs；naive `layers.<n>` parser 对另一 naming family 应失败。
- tied embedding/lm_head duplicate ownership fixture 必须被覆盖检查拒绝。
- 未归属 final norm/辅助 trainable param 必须失败。

## IMPLEMENT / GREEN

- 通过 module structure/explicit adapter 识别逻辑层；不确定时要求显式 mapping。
- 输出每个 parameter identity→logical layer/owner。
- 实现零散参数相邻较小侧、平局前侧规则；记录 tied identity。

## HARDEN

- tied/untied、bias/no-bias、极大 embedding、零参数模块、不同顺序。
- 真实约160M HF config 仅初始化 model structure或meta device（按可行性）并生成摘要。
- 所有 trainable parameter恰好一次。

## Miyabi Final Gate

不适用：CAP-BASE-TRAINING 尚未建立，首次 9N gate 在 `S1-13`。

## CHECK

- Checker 提供第三个小 naming variation或显式 mapping case。
- 核对 forward order与逻辑层顺序。

## PERSIST 输出

- logical-layer registry
- model adapter docs
- coverage reports for ≥2 naming families
- A-FRAG-01 evidence

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- ≥2 naming families 覆盖率 100%、tied/未归属参数反例保持先红后绿、Checker 第三变体通过即关闭；
- 不追加更多 model family，不做 fragment 切分或 encoder-decoder/MoE。
