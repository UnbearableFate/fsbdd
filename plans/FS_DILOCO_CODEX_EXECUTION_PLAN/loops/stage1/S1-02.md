## 单一目标

按同步字节数将完整逻辑层确定性划分为 F 个连续非空 fragments，最小化最大 fragment 并生成冻结摘要/digest。

## 非目标

- 不拆层
- 不实现 balanced-tensor
- 不运行中重分片

## ORIENT

Codex 在修改前必须落盘：

- 当前 source spec hashes、branch/base commit 与 dirty state；
- 前置 loops 和 acceptance 是否有可复算证据；
- 当前唯一 failing gap；
- 预计修改文件与不会修改的接口；
- 本 loop 的资源、walltime、model/data/config；
- 适用时 compatible 9N baseline ID、loss/runtime阈值和fault/heterogeneity overlay；
- `miyabi-development` commit 与 host routing（涉及 Miyabi 时）。

ORIENT 结果不完整时不得进入 RED。

## SPECIFY / RED

- exhaustive tiny layer-size cases，贪心但非最优算法必须在至少一个 case 失败。
- 相同尺寸 tie-break 不稳定实现必须在重排/多进程下产生不同 digest并失败。
- F<=1生产模式、F>=L、空 fragment、参数重复/遗漏全部失败。

保存失败命令、exit code、fixture/config、seed、stdout/stderr。RED 必须在错误或缺失实现上确实失败。

## IMPLEMENT / GREEN

- 实现 constrained partition（DP或可证明等价）与固定靠前 tie-break。
- 计算 sync dtype bytes，处理超大层单独 fragment。
- 输出 map JSON、digest、层/参数/字节/ownership摘要。

只修当前 RED；额外重构或新策略拆成后续 loop。

## HARDEN

- exhaustive小模型与随机 property；真实160M摘要。
- 不同节点/进程重复生成 digest一致。
- tied weights只计一次；最大/平均比报告。

低层检查未通过时不上更大拓扑。

## Miyabi Final Gate

不适用（基础训练系统尚未完成）

适用时按 `docs/06_8L1S_50X10_GATE.md` 产生新的、不可复用的 run package。队列等待不计 active runtime；所有阈值在提交前冻结。

- Checker 用独立 brute force 验证随机小 case。
- 核对 map在run开始后immutable。

Checker 使用新上下文和 `templates/CHECKER_REPORT.md`，不得仅复述 Maker 结论。

## PERSIST 输出

- fragment map implementation
- map report
- brute-force comparison
- A-FRAG-01..03 evidence

另必须更新：

- `plans/PROGRESS.yaml`
- `plans/ACCEPTANCE_TRACEABILITY.csv`
- loop evidence index/checksums
- 下一最小 failing gap

## 完成定义

- RED 在错误实现上失败；
- GREEN 与 HARDEN 全通过；
- 本 loop 相关 requirement 未被隐式改写；
- 适用时新的 9N 50×10 门禁通过；
- Checker 为 `PASS` 或允许关闭的 `PASS_WITH_FOLLOWUPS`；
- 证据、config、commit 与进度已持久化；
- 没有未登记 blocker。
