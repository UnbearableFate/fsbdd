# S1-02：Layer-aligned 连续均衡 Fragment Map

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage1 |
| 前置 loops | S1-01 |
| 规范条款 | FRAG-01, FRAG-02, FRAG-03, FRAG-04, FRAG-05, FRAG-06, FRAG-07, FRAG-08 |
| Acceptance | A-FRAG-01, A-FRAG-02, A-FRAG-03 |
| 最高资源级别 | local CPU + Miyabi 1-node |
| 9 节点门禁 | 不适用（首次 gate 在 `S1-13`） |

## 单一目标

按同步字节数将完整逻辑层确定性划分为 F 个连续非空 fragments，最小化最大 fragment 并生成冻结摘要/digest。

## 非目标

- 不拆层
- 不实现 balanced-tensor
- 不运行中重分片

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 FRAG-01..08 与 A-FRAG-01..03；
- brute-force 对照的搜索空间上限、随机 property 种子与 exhaustive case 集；
- fragment map digest 的规范序列化（字段顺序、dtype 字节口径）先于实现冻结。

## SPECIFY / RED

- exhaustive tiny layer-size cases，贪心但非最优算法必须在至少一个 case 失败。
- 相同尺寸 tie-break 不稳定实现必须在重排/多进程下产生不同 digest并失败。
- F<=1生产模式、F>=L、空 fragment、参数重复/遗漏全部失败。

## IMPLEMENT / GREEN

- 实现 constrained partition（DP或可证明等价）与固定靠前 tie-break。
- 计算 sync dtype bytes，处理超大层单独 fragment。
- 输出 map JSON、digest、层/参数/字节/ownership摘要。

## HARDEN

- exhaustive小模型与随机 property；真实160M摘要。
- 不同节点/进程重复生成 digest一致。
- tied weights只计一次；最大/平均比报告。

## Miyabi Final Gate

不适用：CAP-BASE-TRAINING 尚未建立，首次 9N gate 在 `S1-13`。

## CHECK

- Checker 用独立 brute force 验证随机小 case。
- 核对 map在run开始后immutable。

## PERSIST 输出

- fragment map implementation
- map report
- brute-force comparison
- A-FRAG-01..03 evidence

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- exhaustive/property 与独立 brute-force 一致、digest 跨进程/节点稳定、160M 摘要生成即关闭；
- 不做运行时重分片、balanced-tensor 或性能调优。
