# S1-11：Atomic Global Commit 与 Consumed Frontier

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage1 |
| 前置 loops | S1-03, S1-05, S1-10 |
| 规范条款 | SYNC-08, GLOBAL-02, GLOBAL-03, FS-03, INV-03, INV-05, PROP-06 |
| Acceptance | A-GLOBAL-01, A-GLOBAL-02, A-PROP-03 |
| 最高资源级别 | local + Miyabi 2-node |
| 9 节点门禁 | 不适用（首次 gate 在 `S1-13`） |

## 单一目标

将new params、outer state、version、selected/consumed frontiers与policy identity作为一个逻辑整体发布；失败publication不得消费proposal。

## 非目标

- 不做完整Stage3 kill矩阵
- 不做历史event log
- 不引入global head

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 SYNC-08、GLOBAL-02/03、FS-03、INV-03/05、PROP-06；
- publication 步骤级故障注入点清单在 RED 前列全（进程内 hooks）；
- “publication 成功即 authority/consumption 生效”的观察点与重放判定。

## SPECIFY / RED

- 分别发布params和outer state的unsafe实现，在中断点读取应失败。
- 在visibility成功前写consumed frontier的实现导致retry丢proposal并失败。
- version跳号/覆盖同version不同content必须失败。

## IMPLEMENT / GREEN

- 构造immutable global object集合与single current record。
- publication success即authority/consumption生效；失败保留旧current。
- 每fragmentversion恰好+1；old temp由GC处理。

## HARDEN

- 每个publication step故障注入（进程内）；duplicate retry；reader并发。
- selected set/weights固定后late proposal进下一轮。
- current record完整性/identity。

## Miyabi Final Gate

不适用：CAP-BASE-TRAINING 尚未建立，首次 9N gate 在 `S1-13`。

## CHECK

- Checker从旧current重放失败publication，确认proposal仍eligible。
- 核对无独立latest params/state。

## PERSIST 输出

- global commit implementation
- interruption tests
- consumption traces
- A-GLOBAL/A-PROP evidence

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- 全部注入点重放后只见旧/新完整 state、失败 publication 不消费 proposal 即关闭；
- 完整 kill 矩阵与真实进程 kill 留给 Stage 3。
