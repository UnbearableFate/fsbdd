## 单一目标

从冻结HF初始模型创建version 0 fragments、outer state和current records；读取per-fragment authority而不依赖global head或历史扫描。

## 非目标

- 不实现outer update
- 不实现learner训练
- 不组装每步完整checkpoint

## ORIENT

Codex 在修改前必须落盘：

- 当前 source spec hashes、branch/base commit 与 dirty state；
- 前置 loops 和 acceptance 是否有可复算证据；
- 当前唯一 failing gap；
- 预计修改文件与不会修改的接口；
- 本 loop 的资源、walltime、model/data/config；
- 适用时 compatible 9N baseline ID、loss/runtime阈值和fault/heterogeneity overlay；
- `miyabi-development` commit 与 host routing（涉及 Miyabi 时）。

ORIENT 结果不完整时不得进入 RED。

## SPECIFY / RED

- bootstrap缺任一fragment/current/outer state时reader必须失败。
- 重复bootstrap同run identity不得覆盖不同content。
- 历史目录增加1万假对象时正常启动读取次数不得增长。

保存失败命令、exit code、fixture/config、seed、stdout/stderr。RED 必须在错误或缺失实现上确实失败。

## IMPLEMENT / GREEN

- 实现bootstrap CLI、version0 payloads、outer state初始化、current record。
- 实现current snapshot loader和version vector。
- base retention抽象从一开始按 `S_max+1`，此时只保留current。

只修当前 RED；额外重构或新策略拆成后续 loop。

## HARDEN

- 中断bootstrap、重复执行、wrong map/config identity。
- 不同fragments独立current，无global共同commit。
- storage live-set size checker。

低层检查未通过时不上更大拓扑。
