# S1-04：Bootstrap、Per-fragment Current 与 Bounded Global State

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage1 |
| 前置 loops | S1-02, S1-03 |
| 规范条款 | SYNC-02, GLOBAL-01, GLOBAL-03, GLOBAL-06, FS-03, FS-04, FS-06, FS-10 |
| Acceptance | A-GLOBAL-02 |
| 最高资源级别 | local + Miyabi 2-node |
| 9 节点门禁 | 不适用（首次 gate 在 `S1-13`） |

## 单一目标

从冻结HF初始模型创建version 0 fragments、outer state和current records；读取per-fragment authority而不依赖global head或历史扫描。

## 非目标

- 不实现outer update
- 不实现learner训练
- 不组装每步完整checkpoint

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 SYNC-02、GLOBAL-01/03/06、FS-03/04/06/10；
- “正常启动读取次数只与 F 相关”的 I/O 计数器位置与统计区间；
- bootstrap 幂等/中断判定：何为同 run identity、何为不同 content。

## SPECIFY / RED

- bootstrap缺任一fragment/current/outer state时reader必须失败。
- 重复bootstrap同run identity不得覆盖不同content。
- 历史目录增加1万假对象时正常启动读取次数不得增长。

## IMPLEMENT / GREEN

- 实现bootstrap CLI、version0 payloads、outer state初始化、current record。
- 实现current snapshot loader和version vector。
- base retention抽象从一开始按 `S_max+1`，此时只保留current。

## HARDEN

- 中断bootstrap、重复执行、wrong map/config identity。
- 不同fragments独立current，无global共同commit。
- storage live-set size checker。

## Miyabi Final Gate

不适用：CAP-BASE-TRAINING 尚未建立，首次 9N gate 在 `S1-13`。

## CHECK

- Checker统计正常启动I/O只与F相关。
- 核对version每次只能+1的schema约束。

## PERSIST 输出

- bootstrap command
- version0 state
- bounded-state checker
- A-GLOBAL-02 initial evidence

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- bootstrap/restart/bounded-discovery 断言通过、启动 I/O 与历史体积无关即关闭；
- 不实现 outer update、learner 训练或每步完整 checkpoint。

资源 ≤ L2。PERSIST 后写 compact handoff 并结束 session。
