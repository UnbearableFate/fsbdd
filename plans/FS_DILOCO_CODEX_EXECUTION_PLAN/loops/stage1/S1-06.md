# S1-06：Torch/HF Learner Inner Training Core

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage1 |
| 前置 loops | S1-00, S1-01 |
| 规范条款 | LEARN-01, LEARN-02, PROG-04, PROG-05, TEL-01, TEL-04 |
| Acceptance | 本 loop 为后续 acceptance 提供组成证据 |
| 最高资源级别 | Miyabi 1 compute node |
| 9 节点门禁 | 不适用（首次 gate 在 `S1-13`） |

## 单一目标

实现单GPU、单进程、独立数据shard的自定义HF causal LM训练循环，暴露完整optimizer-step安全边界、tokens/loss/throughput与per-fragment counters。

## 非目标

- 不发布proposal
- 不采用global fragment
- 不使用DDP/Trainer控制global_step

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 LEARN-01/02、PROG-04/05、TEL-01/04；
- 冻结两份 workload identity：9N 回归 GPT-2 small（见 `docs/06`）与正式 160M profile——Pythia 风格 ~160M + FineWeb-Edu/C4 独立 shard 的具体 repo/revision/tokenizer/预处理，在本 loop 内以 ADR 冻结（不迟于 HARDEN），供 S1-13 long run 直接使用；
- 10-step smoke 的 loss/throughput 权威观察点与聚合定义（共同区间，不合成 rank-local rates）。

## SPECIFY / RED

- 真实tiny HF model/data 10-step test：参数不变、loss缺失或NaN时失败。
- gradient accumulation fixture证明micro-batch不增加local step。
- 扫描运行时确保未初始化torch.distributed process group。

## IMPLEMENT / GREEN

- 加载冻结model/tokenizer/dataset manifest；AdamW inner optimizer；scheduler。
- 每完整optimizer.step后emit safe-boundary event并增加各fragment local steps/tokens。
- structured JSONL loss/throughput；独立learner seed/shard。

## HARDEN

- bf16/fp32（环境支持时）、grad accumulation、padding token count、resume-from-global initialization。
- 1-node GPT-2 small + WikiText-2 raw packed-512 真实 10-step smoke；校验预训练参数、tokenizer、dataset revision/hash 与 offline-only 加载。
- 正式 160M profile 另做 10-step smoke，为 Stage 1 M=4/≥1B-token long run 排雷；两份证据分开记录。
- 慢数据/empty batch/overflow错误传播。

## Miyabi Final Gate

不适用：CAP-BASE-TRAINING 尚未建立，首次 9N gate 在 `S1-13`。

## CHECK

- Checker核对loss对应真实参数更新。
- 核对每learner没有共享optimizer/RNG/data cursor。

## PERSIST 输出

- learner core
- tiny/real 10-step evidence
- data/model manifests
- local step/token semantics report

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- tiny、GPT-2 small、160M 三份 10-step smoke 证据齐备且无 torch.distributed 即关闭；
- 不发布 proposal、不采用 global fragment、不做吞吐优化。
