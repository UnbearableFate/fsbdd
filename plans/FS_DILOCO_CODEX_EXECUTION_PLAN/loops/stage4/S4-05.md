# S4-05：Profile B 实跑、Simulator 对齐与 Stale Acceptance Gate

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage4 |
| 前置 loops | S4-04 |
| 规范条款 | STALE-02, STALE-06, STALE-07, REPORT-01 |
| Acceptance | A-STALE-07 |
| 最高资源级别 | Miyabi 9 nodes |
| 9 节点门禁 | 强制：见本卡 Miyabi Final Gate 节与 `docs/06_8L1S_50X10_GATE.md` |

## 单一目标

用M=8、2≤Q<M、Q_fresh≥1、Smax=1、有限grace与异构注入运行Profile B；stale接受率>5%且与Stage0-A预测偏差≤2×。

## 非目标

- 不做最终质量结论
- 不事后调异构直到好看
- 不取消fresh-only对照

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 STALE-02/06/07、REPORT-01；
- stale acceptance rate 的分子/分母与统计窗口（哪些 cycle 计入、按 token 还是按 proposal）提交前冻结；
- 与 simulator 对齐的输入参数来源冻结：实测 step time、visibility delay 如何回填 simulator；偏差 ≤2× 的比较公式；
- 异构 profile 按 Stage 0 预测预注册，不得事后调参直到好看。

## SPECIFY / RED

- 提交前根据Stage0预测冻结速度/latency profile与expected range。
- 若无真实stale selected、acceptance≤5%或偏差>2×，gate RED。
- 缺fresh/stale/rejection/weight mass metrics时report checker失败。

## IMPLEMENT / GREEN

- 完善Profile B config和heterogeneity injection。
- 运行fresh-only同配置参考（门禁可短run）。
- 输出accepted-token efficiency、discard、update intervals、staleness distribution。

## HARDEN

- 至少一个repeat；检查注入实际速度比。
- visibility delay/offset未意外主导。
- 9N H=50/global10是真实主证据。

## Miyabi Final Gate

强制：按 `docs/06_8L1S_50X10_GATE.md` 提交新的、不可复用的 8+1/50×10 run package，loss/runtime/topology/protocol gates 全部通过；阈值提交前冻结，队列等待不计 active runtime。

本 loop 的 gate run 即 Profile B 主证据 run（异构注入、stale accepted >5%）；fresh-only 参考对照可为短 run，与 gate run 分开核算。

## CHECK

- Checker与simulator相同参数重跑/抽查。
- 确认comparison只差S_max相关允许轴。

## PERSIST 输出

- Profile B configs
- simulation-vs-real report
- A-STALE-07 evidence
- new 9N stale gate

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- 按冻结口径 stale accepted >5% 且与 simulator 偏差 ≤2×、REPORT-01 字段齐备、≥1 次 repeat 即关闭；
- 质量结论留给 S4-06；不取消 fresh-only 对照。
