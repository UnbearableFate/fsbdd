# S4-01：`S_max=1` Base History Window 与 Bounded GC

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage4 |
| 前置 loops | S3-04 |
| 规范条款 | STALE-02, STALE-03, SYNC-02, FS-06, FS-09 |
| Acceptance | 本 loop 为后续 acceptance 提供组成证据 |
| 最高资源级别 | Miyabi 2/9 nodes |
| 9 节点门禁 | 强制：见本卡 Miyabi Final Gate 节与 `docs/06_8L1S_50X10_GATE.md` |

## 单一目标

将per-fragment base parameter retention从current-only扩为current+前1版，保持固定窗口、content identity可读和异步GC。

## 非目标

- 不接受stale contribution（下一loop）
- 不支持S_max>1作为必需
- 不保存全历史

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 STALE-02/03、SYNC-02、FS-06/09；
- live-set 统计口径：何为 authoritative objects、与 N updates 无关的判定公式；
- 100+ 小 update bound test 的预算与采样点。

## SPECIFY / RED

- S_max=1时缺old base读取失败；S_max=0时多保留且authority依赖旧base的test失败。
- 经过N updates storage live-set随N线性增长必须失败。
- GC提前删仍可能eligible base的fixture失败。

## IMPLEMENT / GREEN

- 参数化window size S_max+1；current publication后更新retention。
- base by version/content identity lookup。
- 超窗标记并异步GC，不影响current。

## HARDEN

- S_max切换0/1、restart、delayed GC、orphan。
- 100+小update storage bound test。
- 9N S_max=1运行但可保持fresh selection，检查窗口。

## Miyabi Final Gate

强制：按 `docs/06_8L1S_50X10_GATE.md` 提交新的、不可复用的 8+1/50×10 run package，loss/runtime/topology/protocol gates 全部通过；阈值提交前冻结，队列等待不计 active runtime。

本 loop 的 gate run 以 S_max=1 运行但可保持 fresh selection；analyzer 检查 base window identities 与 live-set 有界。

## CHECK

- Checker统计live authoritative objects与N无关。
- 9N gate检查base window identities和loss/runtime。

## PERSIST 输出

- base history implementation
- bounded storage evidence
- new 9N gate package

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- window 切换/restart/GC 断言通过、live-set 与 N 无关、9N gate 通过即关闭；
- 不接受 stale contribution（S4-02），不支持 S_max>1 主路径。
