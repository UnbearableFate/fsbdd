## 单一目标

在selected set上应用 `tokens/(1+lambda*s)`，正确处理未选proposal、same-base trajectory一次消费与延迟旧publication不回退latest。

## 非目标

- 不做lambda消融结论
- 不把未选择视为消费
- 不允许同base靠新sequence重复贡献

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 STALE-05/08/10、PROP-04/06；
- weight golden vectors 直接取自 S0C-02，不新造；
- consumption frontier 原子推进的观察点与重放判定；单元 gate run 的双断言 analyzer 先行实现。

## SPECIFY / RED

- weight property/golden先红。
- 同base sequence replacement在一次成功后再被消费失败。
- 旧publication晚完成覆盖latest失败。
- 未选择proposal被错误consume失败。

## IMPLEMENT / GREEN

- 计算/记录raw r与normalized w；fp32。
- publication成功原子推进sequence/base frontiers。
- latest monotonic guard；未选保持eligible直至自然失效。

## HARDEN

- lambda 0.5/1/2、tokens extremes、mixed s。
- reordered completion、retry、restart。
- 9N检查fresh/stale weight mass与consumption。

## Miyabi Final Gate

强制，且为 `GU-S4-STALE-SELECT` 单元 gate：按 `docs/06` 提交一次新的 8+1/50×10 run（异构 overlay），analyzer 同时断言 S4-03 mixed-quorum/Q_fresh 判据与本 loop fresh/stale weight mass、same-base 一次消费、无 duplicate contribution。其余 gate 条件不变。

## CHECK

- Checker从raw metadata重算weights/frontiers。
- 9N无duplicate contribution。

## PERSIST 输出

- weight/consumption implementation
- A-STALE-05/A-PROP-04/05 evidence
- new 9N stale gate

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- lambda 消融结论留给 S4-06；不允许同 base 靠新 sequence 重复贡献。
