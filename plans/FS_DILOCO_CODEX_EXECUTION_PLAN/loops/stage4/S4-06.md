# S4-06：Matched-token H3、多种子与 Stage 4 关闭

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage4 |
| 前置 loops | S4-05 |
| 规范条款 | REPORT-01, REPORT-02, DISC-03 |
| Acceptance | A-ALG-02 |
| 最高资源级别 | Miyabi 9 nodes + multi-seed research budget |
| 9 节点门禁 | 强制：见本卡 Miyabi Final Gate 节与 `docs/06_8L1S_50X10_GATE.md` |

## 单一目标

用同一binary完成S_max=0/1 matched-token对照、160–410M、≥3 seeds，评估accepted-token效率和最终eval loss；形成Stage4结论/回退。

## 非目标

- 不混淆更多outer updates/通信
- 不删负面结果
- 不把9N短门禁当质量实验

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 REPORT-01/02、DISC-03；
- 实验注册表在任何 research run 前冻结：matched tokens、seeds（≥3）、允许配置轴、H3 统计检验与阈值、eval protocol（沿用 S1-12 冻结 snapshot）；
- 160–410M 质量 workload identity 沿用/扩展 S1-06 ADR；效率比较 matched-compute 或 matched-communication，质量比较 matched-token。

## SPECIFY / RED

- 实验注册表缺matched tokens/seeds/config diff时失败。
- 两臂binary commit不同或除允许轴外配置不同失败。
- eval snapshot未冻结version vector失败。

## IMPLEMENT / GREEN

- 冻结实验矩阵、token budgets、eval protocol。
- 执行fresh/stale多种子runs；独立aggregation。
- 计算效率提升≥simulation预测50%与eval loss±1σ判定。
- 若失败默认profile回退S_max=0，机制保留。

## HARDEN

- seed-level raw curves、confidence/variation、accepted tokens、bytes/FLOPs/walltime。
- lambda/Qfresh/heterogeneity必要消融按计划。
- 最终commit仍跑新的8+1/50×10门禁。

## Miyabi Final Gate

强制：按 `docs/06_8L1S_50X10_GATE.md` 提交新的、不可复用的 8+1/50×10 run package，loss/runtime/topology/protocol gates 全部通过；阈值提交前冻结，队列等待不计 active runtime。

9N 短 gate 在最终 commit 上通过即可；matched-token 研究 runs 是独立 L4 预算，二者不得互相替代。

## CHECK

- Checker核对matched-token、config diffs、统计和claims。
- 完成全部Stage4 acceptance与checkpoint。

## PERSIST 输出

- matched-token experiment package
- A-ALG-02/H3 report
- negative-result fallback if needed
- Stage4 checkpoint
- new 9N gate package

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- ≥3 seeds 两臂 matched-token 完成、H3 判定与回退决策落盘、Stage 4 checkpoint 与全部 acceptance 关闭即停止；
- 负面结果保留并报告；不把 9N 短 gate 当质量实验。
