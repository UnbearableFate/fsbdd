# S4-03：Fresh Anchor、Readiness 与 Deterministic Candidate Selection

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage4 |
| 前置 loops | S4-02 |
| 规范条款 | STALE-06, STALE-07, STALE-09, SYNC-03, SYNC-09 |
| Acceptance | A-STALE-06 |
| 最高资源级别 | Miyabi 2/9 nodes |
| 9 节点门禁 | 强制：见本卡 Miyabi Final Gate 节与 `docs/06_8L1S_50X10_GATE.md` |

## 单一目标

实现eligible distinct≥Q且fresh distinct≥Q_fresh的readiness；超额候选按低staleness→大有效tokens→新sequence→learner ID确定选择。

## 非目标

- 不修改weight公式
- Q_fresh=0仅实验配置
- 不做adaptive policy

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 STALE-06/07/09、SYNC-03/09；
- 选择序 tie-break 的全序定义（staleness→有效 tokens→sequence→learner ID）冻结为可测试常量；
- GU-S4-STALE-SELECT 单元在 PROGRESS.yaml 登记；Q_fresh=0 实验旗标的显式化方式。

## SPECIFY / RED

- 全stale候选在Q_fresh=1时错误推进必须失败。
- 目录/到达顺序改变selected set必须失败。
- 同learner多候选绕过one-per-learner失败。

## IMPLEMENT / GREEN

- fresh/stale计数分开；readiness和grace结合。
- deterministic sort/select；freeze selected set。
- Q_fresh=0需显式experimental标志。

## HARDEN

- mixed quorum、ties、late fresh、candidate变too-stale。
- fairness across fragments。
- 9N heterogeneity产生mixed fresh/stale。

## Miyabi Final Gate

本 loop 属于预注册 gate 单元 `GU-S4-STALE-SELECT`（S4-03+S4-04）：允许以确定性选择的 L1/L2 证据与 Checker PASS 先关闭本 loop，9N gate 义务由 S4-04 的单元 run 一并履行。该 run 使用异构 overlay，analyzer 必须同时断言“每次成功 update ≥ Q_fresh fresh”（本 loop）与 weight mass/consumption（S4-04）。run 失败且根因涉及本 loop 时两个 loop 一并重开；单元内不得插入其他实现 loop。

## CHECK

- Checker重排输入并重算。
- 9N每次成功update至少Q_fresh fresh。

## PERSIST 输出

- selection/readiness implementation
- mixed quorum traces
- A-STALE-06 evidence
- new 9N stale gate

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- mixed quorum/确定性选择/重放断言全部通过、Q_fresh 约束在全 stale 场景正确阻止推进即关闭；
- 9N gate 义务由单元在 S4-04 关闭；不修改 weight 公式。
