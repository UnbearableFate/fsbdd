# S3-03：Global Publication Crash Matrix

| 字段 | 值 |
|---|---|
| Stage | stage3 |
| 前置 loops | S3-02 |
| 规范条款 | REC-03, FS-09, GLOBAL-02, INV-03 |

| 9 节点门禁 | 强制：见本卡 Miyabi Final Gate 节与 `docs/06_8L1S_50X10_GATE.md` |

## 单一目标

在payload写入、payload完成、visibility替换前/后等点kill syncer，重启后只观察旧完整或新完整state，永无半提交。

## 非目标

- 不要求清除所有orphan后才恢复
- 不做存储级事务
- 不扩展为exact replay

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 REC-03、FS-09、GLOBAL-02、INV-03；
- kill-point 矩阵（payload 写入/完成、visibility 替换前/后）与每点重复次数预注册；
- storage snapshot 的采集时点与新旧 state 合法性比对方法；单元 fault tape 内容冻结。

## SPECIFY / RED

- 逐阶段fault hooks；unsafe分离records实现至少一个点出现混合state并失败。
- publication前consumed生效的fixture失败。
- orphan存在时reader误发现的fixture失败。

## IMPLEMENT / GREEN

- 完善fault injection hooks与restart verifier。
- current record作为唯一authority；temp/orphan不被discovery。
- GC异步回收。

## HARDEN

- 每个kill点重复；reader并发；FS visibility delay。
- params/outer/version/frontier/content identity全组合校验。
- old/new合法结果计数。

## Miyabi Final Gate

强制，且为 `GU-S3-CRASH` 单元 gate：按 `docs/06` 提交一次新的 8+1/50×10 independent-jobs run，预注册 fault tape 同时覆盖 S3-02 syncer restart 断言与本 loop 的 payload/visibility 前后 kill 点；恢复后完成 cycle 10。其余 gate 条件不变。

## CHECK

- Checker不信任汇总，直接检查storage snapshot与records。
- 9N gate预注册一个/多个kill点，恢复后完成cycle10。

## PERSIST 输出

- crash matrix harness
- storage snapshots
- A-REC-03 report
- new 9N fault gate

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- 全部 kill 点重复注入后只见旧/新完整 state、orphan 不被 discovery、GU-S3-CRASH 单元 gate run 通过即关闭（同时关闭 S3-02 gate 义务）；
- 不要求清除所有 orphan 才恢复，不做存储级事务。
