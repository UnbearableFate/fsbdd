## 单一目标

learner重启后从current global version vector重建模型，inner optimizer可重新初始化，counters归零，proposal sequence保持单调并继续训练。

## 非目标

- 不做exact replay
- 不保证inner moments恢复
- 不自动重启进程

## ORIENT

Codex 在修改前必须落盘：

- 当前 source spec hashes、branch/base commit 与 dirty state；
- 前置 loops 和 acceptance 是否有可复算证据；
- 当前唯一 failing gap；
- 预计修改文件与不会修改的接口；
- 本 loop 的资源、walltime、model/data/config；
- 适用时 compatible 9N baseline ID、loss/runtime阈值和fault/heterogeneity overlay；
- `miyabi-development` commit 与 host routing（涉及 Miyabi 时）。

ORIENT 结果不完整时不得进入 RED。

## SPECIFY / RED

- 重启后sequence复用导致旧proposal身份冲突的fixture失败。
- 只加载部分current fragments或追历史恢复的实现失败。
- optimizer/counters未按语义重建的test失败。

保存失败命令、exit code、fixture/config、seed、stdout/stderr。RED 必须在错误或缺失实现上确实失败。

## IMPLEMENT / GREEN

- 持久化或安全跳变恢复sequence；加载冻结current vector。
- 重建HF model/inner optimizer、独立data cursor策略明确。
- emit recovery manifest/time。

只修当前 RED；额外重构或新策略拆成后续 loop。

## HARDEN

- 在snapshot/publish/adopt不同点kill learner。
- 重复restart；orphan proposal；wrong run identity。
- independent job重新qsub。

低层检查未通过时不上更大拓扑。

## Miyabi Final Gate

强制：本 loop 结束前提交新的 Miyabi 8 learners + 1 syncer、9 distinct compute nodes、H=50、target_global_cycles=10 run；loss/runtime/topology/protocol gates 全部通过。

适用时按 `docs/06_8L1S_50X10_GATE.md` 产生新的、不可复用的 run package。队列等待不计 active runtime；所有阈值在提交前冻结。

## CHECK

- Checker检查sequence严格单调和无历史扫描。
- 9N gate kill一个learner，≤5min恢复并完成cycle10，loss合法。

Checker 使用新上下文和 `templates/CHECKER_REPORT.md`，不得仅复述 Maker 结论。

## PERSIST 输出

- learner recovery implementation
- recovery traces
- A-REC-02 evidence
- new 9N fault gate

另必须更新：

- `plans/PROGRESS.yaml`
- `plans/ACCEPTANCE_TRACEABILITY.csv`
- loop evidence index/checksums
- 下一最小 failing gap

## 完成定义

- RED 在错误实现上失败；
- GREEN 与 HARDEN 全通过；
- 本 loop 相关 requirement 未被隐式改写；
- 适用时新的 9N 50×10 门禁通过；
- Checker 为 `PASS` 或允许关闭的 `PASS_WITH_FOLLOWUPS`；
- 证据、config、commit 与进度已持久化；
- 没有未登记 blocker。
