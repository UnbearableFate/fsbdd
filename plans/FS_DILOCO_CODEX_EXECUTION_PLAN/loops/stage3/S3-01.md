# S3-01：Learner Kill-Restart Recovery

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage3 |
| 前置 loops | S2-05 |
| 规范条款 | REC-01, REC-05, PROP-04, LEARN-01 |
| Acceptance | A-REC-02 |
| 最高资源级别 | Miyabi independent 9-node jobs preferred |
| 9 节点门禁 | 强制：见本卡 Miyabi Final Gate 节与 `docs/06_8L1S_50X10_GATE.md` |

## 单一目标

learner重启后从current global version vector重建模型，inner optimizer可重新初始化，counters归零，proposal sequence保持单调并继续训练。

## 非目标

- 不做exact replay
- 不保证inner moments恢复
- 不自动重启进程

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 REC-01/05、PROP-04、LEARN-01；
- restart 时间（≤5min）的起止事件定义：kill 确认 → learner 重新发布首个合法 proposal；
- kill 点清单（snapshot/publish/adopt 中）预注册；fault overlay 写入 gate config。

## SPECIFY / RED

- 重启后sequence复用导致旧proposal身份冲突的fixture失败。
- 只加载部分current fragments或追历史恢复的实现失败。
- optimizer/counters未按语义重建的test失败。

## IMPLEMENT / GREEN

- 持久化或安全跳变恢复sequence；加载冻结current vector。
- 重建HF model/inner optimizer、独立data cursor策略明确。
- emit recovery manifest/time。

## HARDEN

- 在snapshot/publish/adopt不同点kill learner。
- 重复restart；orphan proposal；wrong run identity。
- independent job重新qsub。

## Miyabi Final Gate

强制：按 `docs/06_8L1S_50X10_GATE.md` 提交新的、不可复用的 8+1/50×10 run package，loss/runtime/topology/protocol gates 全部通过；阈值提交前冻结，队列等待不计 active runtime。

本 loop 的 gate run 预注册 kill 一个 learner：≤5min 恢复、完成 cycle 10、loss 合法。优先 independent jobs 拓扑。

## CHECK

- Checker检查sequence严格单调和无历史扫描。
- 9N gate kill一个learner，≤5min恢复并完成cycle10，loss合法。

## PERSIST 输出

- learner recovery implementation
- recovery traces
- A-REC-02 evidence
- new 9N fault gate

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- kill 矩阵 + sequence 单调 + 无历史扫描断言通过、9N fault gate 通过即关闭；
- 不做 exact replay、不保证 moments 恢复、不自动重启进程。

## 启动指令（新 session 恢复入口）

```text
前置 S2-05 PASS。分支 codex/S3-01-learner-restart。
目标：learner 重启后从 current global vector 重建、sequence 单调、counters 归零并继续训练。
恢复只读：plans/PROGRESS.yaml、本卡、plans/loop_states/S3-01.yaml、S2-05 handoff。
流程：PREFLIGHT（冻结 restart 时间定义+kill 点清单）→ RED（sequence 复用/部分加载/追历史反例）→ GREEN → HARDEN（不同点 kill、重复 restart、independent 重新 qsub）→ Phase A → 9N fault gate → Phase B。
资源 ≤ L3（independent jobs 优先）。PERSIST 后写 compact handoff 并结束 session。
```
