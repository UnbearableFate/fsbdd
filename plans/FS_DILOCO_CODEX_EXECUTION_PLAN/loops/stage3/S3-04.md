# S3-04：Quorum Availability Boundary、Automatic Resume 与 Stage 3 关闭

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage3 |
| 前置 loops | S3-03 |
| 规范条款 | REC-04, INV-01, SYNC-05 |
| Acceptance | A-REC-04 |
| 最高资源级别 | Miyabi independent 9-node jobs |
| 9 节点门禁 | 强制：见本卡 Miyabi Final Gate 节与 `docs/06_8L1S_50X10_GATE.md` |

## 单一目标

当某fragment eligible learners<Q时只停止该fragment，其他fragments与learners继续；learner恢复后无人工修改自动续，并完成Stage3全矩阵。

## 非目标

- 不改变Q
- 不把quorum不足当系统错误
- 不做dynamic membership

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 REC-04、INV-01、SYNC-05；
- availability 判定观察点：per-fragment outer count 前进（非 heartbeat），比较窗口冻结；
- Stage 3 全矩阵汇总口径（10 次 syncer kill、learner ≤5min、publication matrix）与已有 loop 证据的引用关系。

## SPECIFY / RED

- kill足够learners使一个fragment不足Q；全局/全部fragments若一起停则失败。
- 恢复learner后需手工清理/重置才能继续则失败。
- learner主训练因syncer停而阻塞则失败。

## IMPLEMENT / GREEN

- 确保per-fragment readiness独立；等待状态非busy loop。
- 角色恢复后latest proposal自动进入固定slots。
- availability/ready queue telemetry。

## HARDEN

- 不同fragment offsets/eligible sets；反复失去/恢复quorum。
- Stage3要求的10次syncer kill、learner recovery与publication matrix汇总。
- 9N independent run在故障后完成10cycles。

## Miyabi Final Gate

强制：按 `docs/06_8L1S_50X10_GATE.md` 提交新的、不可复用的 8+1/50×10 run package，loss/runtime/topology/protocol gates 全部通过；阈值提交前冻结，队列等待不计 active runtime。

本 loop 的 gate run 预注册 quorum 丢失/恢复场景（independent jobs），故障后仍完成 10 cycles；同时汇总 Stage 3 全矩阵。

## CHECK

- Checker检查其他fragment真实outer count前进而非仅heartbeat。
- 完成Stage3 checkpoint和全部REC acceptance。

## PERSIST 输出

- quorum scenario trace
- A-REC-04 evidence
- Stage3 full matrix/checkpoint
- new 9N fault gate

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- 单 fragment 停/其他前进、恢复自动续、Stage 3 全矩阵汇总与 checkpoint 关闭即停止；
- 不改变 Q、不做 dynamic membership。

```text
资源 ≤ L4（矩阵汇总）。PERSIST 后写 compact handoff 并结束 session。
```
