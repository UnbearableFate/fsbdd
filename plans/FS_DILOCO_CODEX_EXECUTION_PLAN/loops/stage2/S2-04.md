## 单一目标

实现可重算的learner/syncer/storage/algorithm结构化指标和端到端snapshot/write/discovery/read/adopt分解；telemetry不参与correctness。

## 非目标

- 不让metrics决定commit
- 不只打印人类日志
- 不改变算法

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 TEL-01..04、REPORT-01/02、INV-10；
- goodput/pause 的正式测量定义在本 loop 冻结并由 S2-05 沿用：GPU busy 时间来源（CUDA events 或 step 计时，二选一并记录）、common interval、聚合公式；
- analyzer 对缺 event/非单调时间/伪造汇总 fail-closed 的判定清单。

## SPECIFY / RED

- 关闭telemetry后协议仍应正确；依赖metric才能前进的fixture失败。
- 缺关键event或时间不单调时analyzer失败。
- 用伪造汇总而无raw events时evidence checker失败。

## IMPLEMENT / GREEN

- per-role JSONL schemas、event IDs、monotonic spans。
- 实现loss/runtime/topology/protocol gate analyzer。
- 生成latency breakdown、staleness/weights/rejections/bytes/queue图表数据。

## HARDEN

- 日志丢失/截断/重复event，analyzer显式标记不完整。
- 高频metrics开销测量和sampling策略。
- 9N全角色trace可join。

## Miyabi Final Gate

强制：按 `docs/06_8L1S_50X10_GATE.md` 提交新的、不可复用的 8+1/50×10 run package，loss/runtime/topology/protocol gates 全部通过；阈值提交前冻结，队列等待不计 active runtime。

## CHECK

- Checker从raw JSONL独立重算summary。
- 确认关闭telemetry不改变proposal/global identities。

## PERSIST 输出

- telemetry schemas
- analysis tools
- latency report
- A-PERF-06 evidence
- new 9N gate package

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- Checker 能从 raw JSONL 独立重算全部 gate 报告、关闭 telemetry 不改变协议行为、9N 全角色 trace 可 join 即关闭；
- 不让 metrics 进入 correctness，不改变算法。
