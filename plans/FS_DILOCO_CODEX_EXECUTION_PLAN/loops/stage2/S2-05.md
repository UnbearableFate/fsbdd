# S2-05：Goodput 优化与 Stage 2 关闭

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage2 |
| 前置 loops | S2-04 |
| 规范条款 | PERF-01, PERF-02, PERF-04, PERF-05, PERF-06, PERF-07 |
| Acceptance | A-PERF-04, A-PERF-05, A-PERF-06 |
| 最高资源级别 | Miyabi 1/2/9 nodes + 0.5–1B runs |
| 9 节点门禁 | 强制：见本卡 Miyabi Final Gate 节与 `docs/06_8L1S_50X10_GATE.md` |

## 单一目标

在不改算法语义的前提下达到160M和0.5–1B GPU goodput≥95%、snapshot+adoption pause≤2%，完成性能分解和Stage2关闭。

## 非目标

- 不引入多syncer/压缩
- 不为了性能跳过校验
- 不改变H/Q等比较条件

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 PERF-01/02/04..07；
- 0.5–1B 系统 workload identity（模型/数据/tokenizer/预处理 revision）以 ADR 冻结后才允许 L4 run；
- goodput≥95%、pause≤2% 按 S2-04 冻结定义计算，阈值与冷/热 cache 条件提交前冻结；
- 优化逐项开关，每项一个 profile 对照，不做未证实的批量重构。

## SPECIFY / RED

- 建立no-communication local baseline和当前FS path；未达阈值先RED。
- byte accounting出现full model transfer时失败。
- 若提出多syncer但无具体bottleneck profile，PERF-06 checker失败。

## IMPLEMENT / GREEN

- 基于profile做最小优化：buffer reuse、poll cadence、I/O chunk、CPU affinity等，逐项开关。
- 实现visibility-delay injection接口并证明不改变correctness。
- 冻结性能profile。

## HARDEN

- 160M、0.5–1B各跑；冷/热cache条件一致。
- pause、goodput、CPU/FS成本、latency decomposition。
- 回归slow FS有界。

## Miyabi Final Gate

强制：按 `docs/06_8L1S_50X10_GATE.md` 提交新的、不可复用的 8+1/50×10 run package，loss/runtime/topology/protocol gates 全部通过；阈值提交前冻结，队列等待不计 active runtime。

9N gate 必须在最终 commit/最终性能 profile 上通过；160M 与 0.5–1B 阈值 run 可预注册为 stage-level L4 证据，与 gate run 分开核算。

## CHECK

- Checker检查对照可比性和阈值。
- 新的9N gate必须在最终commit/profile上通过。

## PERSIST 输出

- performance report
- A-PERF-04/05/06 evidence
- Stage2 checkpoint
- new 9N gate package

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- 160M 与 0.5–1B 各一次达标（95%/2%）、latency 分解与 slow-FS 回归通过、Stage 2 checkpoint 关闭即停止；
- 未达标时以 profile 证据升级 blocker/ADR，不无证据继续调优。
