# S2-01：异步 GPU→CPU→FS Publication Pipeline

## 元数据

| 字段 | 值 |
|---|---|
| Stage | stage2 |
| 前置 loops | S1-13 |
| 规范条款 | LEARN-05, PERF-02, PERF-03, PERF-05, TEL-01 |
| Acceptance | 本 loop 为后续 acceptance 提供组成证据 |
| 最高资源级别 | Miyabi 1/2/9 nodes |
| 9 节点门禁 | 强制：见本卡 Miyabi Final Gate 节与 `docs/06_8L1S_50X10_GATE.md` |

## 单一目标

把fragment snapshot复制到有界CPU staging并由后台worker写FS，使GPU inner training在copy安全边界后立即继续。

## 非目标

- 不实现adoption优化
- 不扩大queue
- 不改proposal语义

## ORIENT 与 PREFLIGHT

通用 ORIENT/PREFLIGHT 要求见 `AGENTS.md` §4.1、`docs/03_LOOP_ENGINEERING_PROTOCOL.md` 与 `templates/LOOP_CARD.md`，不在此重复；ORIENT 或 PREFLIGHT 不完整时不得进入 RED。本 loop 进入 RED 前必须额外冻结：

- requirement matrix 覆盖 LEARN-05、PERF-02/03/05、TEL-01；
- overlap 测量定义：以 learner 主线程 wall-clock step time 为权威观察点，同 commit 同 config 的同步/异步两臂对照，聚合用 coordinator 共同区间（X-MEASURE-01）；
- GU-S2-ASYNC 单元在 PROGRESS.yaml 登记，S2-02 gate run 的双断言 analyzer 需求写入 handoff。

## SPECIFY / RED

- timing test证明同步FS写占用训练主线程；作为RED。
- 后台异常被吞掉、无限queue、mutable staging payload的fixtures失败。
- snapshot完成前GPU参数继续mutation导致payload不稳定的test失败。

## IMPLEMENT / GREEN

- 使用明确CUDA stream/event或安全copy策略；CPU buffer数量有界。
- 每fragment最多一个in-flight publication，pending latest-wins。
- 后台结果/错误通过typed channel反馈；训练不等FS。

## HARDEN

- slow writer、large fragment、skip/replacement、shutdown。
- 1-node profile snapshot/copy；2-node真实FS。
- 比较同步基线与异步step time。

## Miyabi Final Gate

本 loop 属于预注册 gate 单元 `GU-S2-ASYNC`（S2-01+S2-02）：允许以 2-node overlap 证据与 Checker PASS 先关闭本 loop，9N gate 义务由紧随其后的 S2-02 单元 run 一并履行。该 run 的 analyzer 必须同时断言 upload overlap（本 loop）与 adoption pause（S2-02）；run 失败且根因涉及本 loop 时两个 loop 一并重开。单元内不得插入其他实现 loop。细节见 `docs/06` §6.1 与 `AGENTS.md` §5。

## CHECK

- Checker检查buffer lifetime和主线程wait points。
- 9N run复算upload overlap与loss/runtime。

## PERSIST 输出

- async publisher
- timing trace
- queue bound evidence
- new 9N gate package

另按 `AGENTS.md` §7 更新 PROGRESS、traceability、evidence index、checksums 与 compact handoff。

## 完成定义与停止条件

完成定义见 `AGENTS.md` §7（RED 有效、GREEN/HARDEN 通过、适用 gate 通过、Checker 允许关闭、证据/进度/handoff 持久化）。达到以下条件即停止，不为额外置信度追加运行或重构：

- 同步/异步对照证明主线程不再等待 FS 写、queue/staging bound 断言通过、2-node 证据完备即关闭；
- adoption 侧与 9N run 属于 S2-02；不扩大 queue、不改 proposal 语义。
