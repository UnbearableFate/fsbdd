## 代码与协议检查

- compute-only guard：both the PBS entrypoint and every `smoke-role` call require a short host matching `^mg[0-9]+$` plus non-empty `PBS_JOBID` and `PBS_NODEFILE`.  Login and unallocated-compute fixtures fail closed; the runtime role cannot bypass the library guard merely by invoking the module directly.

Writer publishes the payload before the visibility record; reader waits with `time.monotonic_ns`, validates schema/run/writer host, then checks payload byte count and SHA-256 before atomically acknowledging.

The roles independently reject a writer/reader host collision, and the summarizer cross-checks rank set, roles, run IDs, distinct hosts, reciprocal host identities, payload size/digest, statuses, and the expected positive/negative outcome.

No MPI API, socket, `torch.distributed`, RPC, `-x` export, or network application payload exists in the role implementation.
