- scope：the correction is limited to model-scope enforcement, buffer-policy
  records/coverage, tests and adapter documentation. No fragment partition,
  storage protocol, learner/syncer runtime, algorithm, topology, dependency or
  Torch version changes are present.
- decoder-only fail-closed boundary：`build_logical_layer_registry()` now
  requires `model.config` and rejects `config.is_encoder_decoder` before
  evaluating `explicit or _builtin_mapping(model)`. The exact prior explicit-
  mapping bypass can no longer reach adapter selection.
- forward order：built-ins remain
  `gpt_neox.embed_in -> gpt_neox.layers.0..N-1 -> embed_out` and
  `model.embed_tokens -> model.layers.0..N-1 -> lm_head`. Official HF
  `ModuleList` child order supplies complete block order. Final norms are misc
  state adjacent to the last block and head. Explicit maps expose caller-
  supplied complete block order for checking rather than guessing it from
  parameter-name substrings.
- misc ownership：synchronization bytes of the two adjacent logical layers are
  compared before assignment; `left <= right` implements the required earlier-
  side tie break. Assigned bytes update the selected side deterministically.
- tied ownership：trainable aliases are grouped by parameter-object identity.
  An embedding/head tied object produces one record owned by embedding with all
  aliases and a tied identity; unique head parameters remain with `lm_head`;
  sharing involving another logical layer fails.
- trainable coverage：every trainable Python parameter object must be under one
  logical or misc path. Unowned objects and unsupported cross-layer ownership
  raise. Successful registries independently validate one record per canonical
  parameter identity and report zero duplicate/unowned identities.
- buffer policy：`named_buffers(recurse=True, remove_duplicate=False)` enumerates
  every registered buffer and alias. Each actual alias must occur in the exact
  `reconstructable_buffers` declaration; any omission rejects registry
  construction. Duplicate declarations reject. Successful buffer records bind
  all aliases, shape, dtype, numel and classification into the registry digest,
  while coverage reports total/reconstructable/unclassified counts. This makes
  static-buffer exclusion explicit and prevents undeclared mutable semantic
  buffers from silently passing coverage.
- built-in buffer policy：GPT-NeoX and LLaMA name their known rotary
  `inv_freq`/`original_inv_freq` config-reconstructable buffers. Because actual
  buffers are still enumerated, a library/model variation adding any undeclared
  buffer fails closed instead of inheriting a broad name rule.
- data plane / bounded state / atomic publication / base-consumption /
  numerical reference / resume identity：not implemented or claimed by S1-01.
  Registry and report containers are finite. Selected evidence binds code,
  config, source, skill, execution, roles and paths.
